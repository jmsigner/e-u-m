Veröffentlichungsdatum

15. Juni 2026

Die Benotung für dieses Modul erfolgt anhand einer strukturierten Hausarbeit. Um für die Hausarbeit zugelassen zu werden, muss eine Prüfungsvorleistung absolviert werden, darin werden die wichtigsten Konzepte, Methoden und Begriffe der Vorlesung in einem Multiple-Choice-Test abgefragt.

Für die Hausarbeit verwenden Sie einen bereits erhobenen Datensatz. Es ist auch zulässig eine beretis durchgeführte Studie zu wiederholen. Nähere Details zur Hausarbeit fogen ab Woche 8 des Semesters.

Prüfungsleistung

Ziel

Die Prüfungsleistung besteht aus einer strukturierten Hausarbeit.

Stellen Sie eine Hypothese/Erwartung auf und analysieren Sie dazu einen bereits vorhandenen Datensatz.

Die Bewertung ist in zwei Kategorien aufgeteilt, die im Folgenden ausgeführt werden.

  • Analysen (40%)
  • Schriftliche Ausarbeitung (60%)

Analysen

  1. Code ist reproduzierbar. (60%)
  2. Der Code ist ausreichend dokumentiert und logisch sinnvoll aufgebaut. (25%)
  3. Es gibt eine README-Datei, die beschreibt, wie man den Code und die Analyse ausführen kann. (15%)

Beispiele für gut und schlecht kommentierten Computercode

Schlecht kommentierter Computercode erklärt das Offensichtliche:

library(tidyverse)

# Daten lesen
dat <- read_rds("daten/lynx.rds")

# Lineares Modell anpassen
m2 <- lm(lynx ~ y, data = dat)

# Summary aufrufen
summary(m2)

# Neues Data Frame
nd <- data.frame(y = 35:80)

# Predict
nd$lynx <- predict(m2, newdata = nd)

# Plot erstellen mit xlab und ylab
# und type = "l"
plot(nd$y, nd$lynx,
     xlab = "Breitengrad",
     ylab = "Vorkommenswahrscheinlichkeit",
     type = "l")

# Linie bei 0
abline(a = 0, b = 0, col = "red")
# Linie bei 1
abline(a = 1, b = 0, col = "red")

Während gut kommentierter Computercode einen Schritt weiter geht:

library(tidyverse) # für die Manipulaiton von Daten

# Datensatz mit Luchs-Vorkommens-
# daten (binär, 0/1) laden
dat <- read_rds("daten/lynx.rds")

# Logistisches Regressionsmodell:
# Abhängige Variable: Vorkommen (0/1)
# Prädiktor: Breitengrad (y)
m2 <- lm(lynx ~ y, data = dat)

# Modellgüte und Koeffizienten prüfen
summary(m2)

# Vorhersagedaten für Breitengrade
# Von 35N bis 80N erstellen
nd <- data.frame(y = 35:80)

# Vorkommenswahrscheinlichkeit für
# jeden Breitengrad vorhersagen
nd$lynx <- predict(m2, newdata = nd)

# Ergebnis plotten: Kurve zeigt, wie
# Vorkommenswahrsch. mit dem Breitengrad variiert
plot(nd$y, nd$lynx,
     xlab = "Breitengrad",
     ylab = "Vorkommenswahrscheinlichkeit",
     type = "l")

# Referenzlinien bei 0 und 1: markieren gültige 
# Wahrscheinlichkeitsgrenzen (0% und 100%)
abline(a = 0, b = 0, col = "red")
abline(a = 1, b = 0, col = "red")

Beispiel

Als Beispiel: Ich möchte die Hausarbeit zu einem Occupancy Model durchführen. Dazu habe ich folgende Schritte durchlaufen:

  1. Ich habe <www.datadryad.org> aufgerufen und dort nach occupancy model germany gesucht.
  2. Und mich für die Studie: Ecological drivers of garden dormouse (Eliomys quercinus) occupancy in a human modified landscape in Germany entschieden.

Ich habe mir dann 3) eine Hypothese herausgegriffen (Hypothese 3; https://besjournals.onlinelibrary.wiley.com/doi/full/10.1002/2688-8319.70023):

We also hypothesised that the detection probability of garden dormice may vary with temperature, as higher temperatures can lead to increased activity, making dormice easier to detect, whereas extremely high or low temperatures might reduce detectability due to limited movement as temperature affects their activity patterns and behaviour (Ruf & Geiser, 2015; Torre et al., 2018).

Man kann die Daten herunterladen. Dann wären die nächsten Schritte wären:

  • Daten sichten und eine Erste Abbildung erstellen zu den Rohdaten (z.B. an welcher Falle gab es viele Sichtungen; so eine Abbildung war nicht in der Veröffentichung).
  • Anpassen von 3 Occupancy modellen (jeweils ein Modell; ohne Temperatur, mit Temperatur und und einem quadratischen Effekt von Temperatur für die Detektion); daraus kann ich dann eine Tabelle Erstellen, die die drei Modelle vergleicht.
  • Erstellen einer weiteren Abbildung (ähnlich zu Abbildung 3 in der Veröffentlichung), die den Effekt von Temperatur auf die Detektionswahrscheinlichkeit zeigt.
  • Zusammenfassen und Beschreiben der Ergebnisse.

FAQ

Soll ich eine Fragestellung aus einer Veröffentlichung reproduzieren oder eine neue Fragestellung suchen?

Beides ist zulässig und OK. Wichtig ist, dass die Fragestellung überschaubar ist und gut in dem Zeitraum bearbeitet werden kann.

Soll die Hausarbeit alleine oder in Gruppen bearbeitet werden?

Jede/r muss eine eigene Hausarbeit abgeben, wenn mehrere Studierende an einem Thema/Datensatz arbeiten ist das OK. Aber jede/r muss eine eigene Arbeit abgeben.

Soll die README-Datei als txt sein?

Ja, gerne.

Was sollen wir genau machen? Hausarbeit generell noch unklar

Siehe oben (Gliederung).

Welche Art von Fragestellungen (Umfang, Themenbereich) sind angebracht? Hinsichtlich des Umfangs der Datenauswertung

Siehe weiter oben zur Gliederung und Umfang.

Wenn ich die Daten nachvollziehe bzw nachrechne, entsteht am Ende eine Kopie, wo ist dann mein Eigenanteil?

Hoffentlich sind Sie danach in der Lage die Analysen besser zu verstehen, etwaige Stärken und/oder Schwächen zu sehen. Es geht bei dieser Hausarbeit nicht darum viel neues Wissen zu generieren (wenn das passiert ist das natürlich erfreulich), sondern viel mehr soll es Sie in die Lage versetzten einmal Analysen durchzuarbeiten und die Ergebnisse zu beschreiben und Interpretieren.

Wie ausführlich/kompliziert müssen die statistischen Auswertungen sein? Reicht simple Statistik, wenn sie genug aussagekräftig für die Fragestellung ist?

Bitte nicht komplizierter als nötig machen. Wenn Sie mit einer einfachen Analyse die Fragestellung beantworten können und 2 Abbildungen und eine Tabellen erstellen können, ist das vollkommen ausreichend. Falls Sie nicht sicher sind, fragen Sie mich kurz.

Wie finde die Themenververgabe statt? Ich würde gerne jetzt schon anfangen.

Sie können gerne bereits beginnen. Die Themenvergabe ist frei, sprechen Sie sich einfach kurz mit mir ab.
